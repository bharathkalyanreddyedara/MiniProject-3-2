StegoGuard
Dashboard Documentation

Welcome to StegoGuard! A secured way of detecting malicious images. This project is mainly designed to extract the content which was hidden in an image using LSB technique (Least Significant Bit) and then detect the URLs present within the images hidden. We have used BiLSTM + RandomForest (Hybrid Model) for detecting and declare if the URLs extracted from the image are Benign (Safe) or Not (Malicious).
